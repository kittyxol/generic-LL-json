# Generic Linked-list на Go с поддержкой сериализации в JSON и обратно (MarshalJSON,  UnmarshalJSON)

Проект написан в учебных целях — чтобы разобраться, как работают generics в Go и как реализовать собственные методы `json.Marshaler` / `json.Unmarshaler` для рекурсивных структур данных.
## Что внутри

- `Node[T]` — узел связного списка, хранит значение любого типа `T` и указатель на следующий узел.
- `LinkedList[T]` — сам связный список, хранит указатель на голову (`head`).
- Методы `Append` и `Prepend` — добавление элемента в конец / в начало списка.
- Метод `Len` — подсчёт количества элементов.
- Метод `Print` — вывод списка в консоль в виде `a -> b -> c -> nil`.
- Кастомные `MarshalJSON` / `UnmarshalJSON` для `Node[T]` и `LinkedList[T]` — превращают список в JSON и восстанавливают список обратно из JSON.


## Формат JSON

Список сериализуется в JSON:

```json
{
  "head": {
    "value": "a",
    "child": {
      "value": "b",
      "child": {
        "value": "c"
      }
    }
  },
  "length": 3
}
```

- `value` — значение узла.
- `child` — вложенный следующий узел (или отсутствует, если это последний элемент).
- `length` — количество элементов в списке (считается автоматически при сериализации).

Пустой список сериализуется как `{"length": 0}` — поле `head` опускается благодаря тегу `omitempty`.

`T` может быть любым типом, поддерживаемым `encoding/json`: строка, число, структура и т.д. (см. примеры в `json_test.go` — `string`, `int`, `User`).

## Тесты

Написаны тесты, которые используют библиотеку testify. 
Они проверяют:
- сериализацию (`MarshalJSON`) пустого и непустого списка для разных типов (`string`, `int`, кастомная структура `User`);
- десериализацию (`UnmarshalJSON`) обратно в связный список и корректность восстановленной цепочки узлов.
- Все тесты разбиты на две группы: тесты на `MarshalJSON` (список → JSON) и тесты на `UnmarshalJSON` (JSON → список). Внутри каждой группы список прогоняется для нескольких типов `T`, чтобы убедиться, что обобщённость (generics) работает.
